# Muhammad Hafizuddin — Engineering Portfolio

A static, responsive portfolio designed for GitHub Pages. No build tools or paid hosting required.

## Deploy to your existing GitHub Pages URL

Your site URL is `https://muhhafizuddin-hue.github.io/main/`, corresponding to the repository `muhhafizuddin-hue/main`.

1. Open https://github.com/muhhafizuddin-hue/main
2. Back up any existing website files before replacing them.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` directory **to the repository root**. Do not upload the enclosing `hafizuddin-portfolio` directory as a nested folder.
4. In GitHub repository Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/(root)` (if not already configured).
5. Visit https://muhhafizuddin-hue.github.io/main/ after deployment completes.

## Add your own project photos

Put your photographs into `assets/projects/` with the following names:

- `intellcorr.jpg` — IntellCorr monitoring equipment or site installation
- `cms.jpg` — Corrosion Management System dashboard screenshot
- `pipeline.jpg` — Pipeline monitoring installation
- `farming.jpg` — Precision farming greenhouse and IoT equipment
- `tru.jpg` — Cathodic protection RMU/TRU equipment
- `engineering.jpg` — CAD model, prototype or product validation work

Until a matching image exists, the website displays an attractive technical placeholder automatically. You may change names or add projects by editing the `projects` array in `script.js`. Use landscape images around 1600×1000 pixels, ideally optimized below 500 KB each. Remove confidential details and obtain permission for site/customer photographs.
